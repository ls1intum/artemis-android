Add a centered native grabber to the existing rounded Android composer. Dragging up grows the editor continuously; dragging down shrinks it. A dominant vertical release of at least 24 dp settles in its direction; shorter drags settle at the nearest size. Horizontal movement must not resize. Tap, keyboard activation, and accessible expand/collapse actions provide alternatives. Keep a 48 dp target and a Material capsule. Do not change focus, text, selection, composition, history, or the draft when resizing.

Use up to 240 dp additional editor space in regular-height windows, 120 dp in compact-height windows. The actual parent budget, fixed toolbar, attachments and text size remain authoritative. Preview tiles yield to the editor in very short windows; their inline attachment labels remain editable. Preserve 96 dp of conversation/preview context when space permits; hide the grabber in windows too short for a usable editor plus its controls. Start each gesture from the rendered height, including interrupted animations and constrained expanded layouts. Track the pointer in window coordinates so movement of the grabber itself cannot compound drag deltas. Respect the system animation duration scale; follow the finger without animation while dragging.

Expansion remains inline, with one toolbar and no fullscreen mode. Keep emoji category headers as ordinary transparent grid items, using secondary label typography and normal category capitalization.
